# Ecommerce
human computer interaction and e commerce

## Getting started with HTML + JavaScript

1. Open `/home/runner/work/Ecommerce/Ecommerce/index.html` in your browser.
2. Add your JavaScript code inside `/home/runner/work/Ecommerce/Ecommerce/script.js`.
3. The HTML file already loads `script.js` using:
   ```html
   <script defer src="./script.js"></script>
   ```
4. If you want to run code after the page loads, use:
   ```javascript
   document.addEventListener("DOMContentLoaded", () => {
     // your code here
   });
   ```
